## R1 新增 P2 高count近独立时χ²消减精度回归

输入：

```js
contingencyTest(
  [[5,6],[454545454536,545454545443]],
  {alpha:1-1e-12}
)
```

该表总数N=999999999990，满足合同。最小E是`5 + 1/999999999990`，全部E≥5，status ok正确。

Fraction精确统计量与100位参考：

- χ²=`3.666666666780211111113859892963024321162458114898874872215016048869771e-25`。
- df1，p=`0.9999999999995168569053837759517000136984656906730467994644082513700019`。
- alpha的实际double是`0.999999999999`，应reject false。

修复版7e45fa8实际：

- E右下角=`545454545442.99994`。
- χ²=`6.830065612521397e-21`。
- p=`0.9999999999340594`。
- reject true。

父版840f850同一输入实际：χ²=`3.667318633249195e-25`，p=`0.9999999999995168`，reject false。因此这确实是本次乘除顺序变化触发的相邻域回归，不是只凭新oracle推测。

原因：`src/inference.js:495–497`先形成很大的浮点期望E，再在`pearsonContribution`里计算`O-E`。高count且接近独立时，真实残差约1e-12；大乘积的舍入让某个E误差达到约6.1e-5，平方后主导本应接近零的统计量。

建议：Contingency的整数计数可先用BigInt精确形成残差`D=O*N-r*c`，再转浮点计算贡献，例如利用恒等式`(O-E)^2/E = D^2/(N*r*c)`。不要重新退回先除后乘而复活E=5问题，也不要用全局alpha容差掩盖残差计算。

回归：本表及其转置，在alpha=.05和1-1e-12分别比较；两者都应reject false。保留E=5、5±1/N、高count与原四表。新的目标应同时满足频数阈值分类和近独立统计量精度。

严重度P2的原因：这是支持域内可复现的reject差异，但只在高count近独立、极端接近1的alpha发生；常规alpha=.05下两版都不拒绝。p的绝对误差约6.55e-11，不能把统计量的巨大相对误差误述为普通课堂场景的P0。仍需记录为未解决数值回归。

## R2 P3 CI临界值仍有1ulp严格单调性反例

调用`zTestOneMean({mean:0,variance:1,n:1,confidenceLevel:cl})`：

- cl=`0.49999999999994543`，critical=`0.6744897501959959`。
- 下一个double cl=`0.4999999999999455`，critical=`0.6744897501959958`。

增加confidence后临界值下降`1.1102230246251565e-16`，即1ulp。100位参考分别为：

- `0.674489750195995884982410148279507312797723632603507778769435`
- `0.674489750195995972325461843970024386200297025971647935356064`

精确值应增加。在密集CI网格中共发现14处同类下降，均只有1ulp；公开inverse网格没有下降。

原因在`normalCentralQuantile`的浮点Newton收敛/取值，CI直接以confidence/2调用时覆盖到比公开p-.5路径更细的中央质量步长。

建议：若需要保证相邻double的单调性，给近中心反解增加一致的根包围/停止及取值规则，或采用有单调性保证的策略；不要仅增加固定Newton次数并假设即可解决。

回归：上述两个相邻cl，以及confidence=.5附近密集网格。该项没有可见课堂影响，数值误差仍在约几个ulp，列P3，不重新判定原M2精度修复失败。
