## Supported methods and omitted methods

- Card model is IID with replacement, finite variance; finite-frame design lab is explicitly without replacement within one sample. Do not interchange their SE formulae.
- CLT/CI source pools are finite discrete models. No Normal source-population simulator; non-Normal small-n intervals are approximate. No universal n30 guarantee.
- Mean estimated-s route is a stated large-sample approximation. Repeated estimated-s references use fixed plug-in s, not fresh random sample-variance estimates. No small-sample t/Welch/paired method.
- Official correlation table is a verified subset, with absent versus unimplemented cells distinguished. Ties keep descriptive Spearman but block the ordinary no-ties table inference. No invented exact table p-value. Synthetic dragged points do not establish random sampling or causation.
- GOF UI supports uniform/specified four-class probabilities and Binomial(3,p). Normal/Poisson/continuous-uniform GOF, arbitrary dimensions and exact multinomial tests are absent. Fittingp from original four classes then pooling is descriptive only: standard calibrated p/reject/referenceDF are withheld. No grouped-MLE/bootstrap is claimed. Conditional fixed-margin contingency Monte Carlo cannot substitute for that GOF calibration.
- Low expected frequencies block unqualified chi-square asymptotic inference. Grouping requires meaningful whole categories in O and E; no automatic significance-seeking pooling or Yates correction.
- Finite-frame lab uses12 invented units. Systematic n must divide12. Quota is one explicit deterministic convenience mechanism, not a general theorem about quota bias. DesignSE uses the known complete fictional frame, not one-sample estimatedSE. Missing strata produce unavailable full-target estimates/SE, not zero or raw-mean substitution.
- Normal combination tool has two distinct variables and explicit Normal/independence declarations. No covariance model or non-Normal distribution inference. Zero variance is a point mass.
- Full S1/S2/S3 course coverage, PDF/CDF workbench, histogram/skewness curriculum, general survey inference and all official table rows remain absent/partial as itemized in CURRICULUM-STATUS.md and scope.html.

## Interface and validation limits

Desktop/phone/Teacher screenshots are real Chromium screenshots at specified CSS viewports; they are not physical-device trials. Teacher Sampling has focused stages; some other experiments remain scrolling workspaces even in Teacher mode. Back-row projector readability, screen-reader speech, mobile OS keyboard behaviour, multiple browsers/OS fonts and real learner comprehension/timing/retention/exam transfer are unmeasured. HTML guide is preferable to relying on PDF accessibility; PDFs have not been certified as tagged accessible documents.

Developer checks cover named controls, keyboard routes, responsive overflow, reduced motion, hidden calculated outputs, seed/state/cap regression, static module closure and a lightweight performance run. They are not a WCAG conformance audit or performance guarantee. The named original reviewer whose browser tool was unavailable remains BLOCKED0/8 historically; later independent Chromium checks are separate evidence.

No real students, real student data, paid services, purchases or paid draws. Runtime calculation uses local JS with local font fallbacks and no analytics. No permanent browser persistence is implemented; keep the seed/configuration or the source package to reproduce an experiment. Closing/refreshing may start a fresh session.
